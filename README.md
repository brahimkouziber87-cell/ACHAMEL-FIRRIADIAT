# المنظومة الرقمية الشاملة لأستاذ مادة الرياضيات
## التدبير التربوي والإداري والهندسة البيداغوجية والتقويم (السلك الثانوي التأهيلي)

تطبيق متكامل وموحد يجمع بين:
1. **منظومة التدبير التربوي لمادة الرياضيات:** تدبير الحصص والغياب والمواظبة، نقط الفروض والمراقبة المستمرة، دفتر النصوص الإلكتروني، استعمال الزمن، ولوحة القيادة الإحصائية ومؤشرات الأداء.
2. **منصة الهندسة البيداغوجية والتقويم الرياضي (مدمجة كتبويب رئيسي):** إعداد الفروض المحروسة والمنزلية (DS/DM) وشبكات التقويم وجداول التخصيص وفق المذكرة 142-08، الجذاذات التربوية وفق التوجيهات التربوية 2007، الروائز التشخيصية، ماسح QCM الذكي، محرر LaTeX، ومختبر بايثون وولفرام ألفا.

---

## بنية المشروع الموحد (Project Architecture)

- `server.ts`: خادم Express الموحد الذي يجمع مسارات التدبير والذكاء الاصطناعي مع مسارات الهندسة البيداغوجية.
- `pedagogyRoutes.ts`: وحدة المسارات الخلفية المستقلة لمنصة الهندسة (توليد الوثائق، استنساخ الفروض، محاكاة الامتحانات، وخدمات GeoGebra و Wolfram).
- `index.html`: الواجهة الرئيسية الحاضنة لجميع التبويبات مع تبويب **«الهندسة والتقويم»** الجديد وزر الإطلاق السريع في لوحة الأيقونات.
- `src/main.tsx`: نقطة الربط وتفعيل التحميل الكسول (Lazy Loading) للمنصة عبر React 19.
- `src/pedagogy/`: مجلد مستقل ونظيف يحوي كافة استوديوهات، ومكونات، ومقررات (Curriculum DB)، ومولدات منصة الهندسة البيداغوجية.
- `public/`: الأصول الثابتة، وملفات المحرك الإداري، وواجهات PWA.

## متطلبات التشغيل (Prerequisites)

- **Node.js** (إصدار 18 أو أحدث)
- **NPM** أو **Bun**

---

## خطوات التشغيل السريع (Quick Start)

### 1. تثبيت الحزم المشتركة:
```bash
npm install
```

### 2. ضبط مفتاح الذكاء الاصطناعي (Gemini API Key):
أنشئ ملف `.env` في المجلد الرئيسي وضع به مفتاح Gemini الخاص بك:
```env
GEMINI_API_KEY="your-gemini-api-key-here"
```

### 3. تشغيل وضع التطوير (Development Mode):
```bash
npm run dev
```
سيفتح التطبيق تلقائياً على الرابط: `http://localhost:3000`

### 4. تشغيل التطبيق في وضع الإنتاج أو النوافذ:
- **تشغيل محلي مباشر:** اضغط مرتين على ملف `تشغيل_المنظومة.bat` أو `Run_App.bat`.
- **نسخة سطح المكتب (Desktop Electron):**
  ```bash
  npm run desktop
  ```
- **نسخة الأندرويد (Capacitor Android):**
  ```bash
  npm run android:sync
  ```
